# 2D-drone
Симуляция 2D-дрона с грузом на тросе в среде Gymnasium (уравнения движения, RK4, ветер Орнштейна - Уленбека). Агент на PPO (Stable-Baselines3, PyTorch) учится наводить дрон, гасить раскачку груза при смене массы и плавно сажать его.

# Структура проекта:

drone_env.py - физическое ядро и среда на базе Gymnasium (DroneSlungLoadEnv). Описывает динамику 2D-квадрокоптера с грузом на тросе (уравнения Лагранжа 2-го рода, численное интегрирование методом Рунге - Кутты 4-го порядка с шагом 0.02 с), модель ветра по процессу Орнштейна - Уленбека, переменная масса груза, логика мягкой посадки и отрисовка сцены через pygame-ce. Нужен как основа для обучения и запуска любых агентов в единой физической среде.

train.py - скрипт обучения агента методом PPO (Stable-Baselines3, PyTorch). Проверяет корректность среды через check_env, запускает параллельные симуляции на нескольких средах, обучает модель на случайных массах груза и сценариях посадки, пишет логи в TensorBoard и сохраняет лучшую версию весов в models/.

test_interactive.py - интерактивный стенд для проверки обученной модели. Загружает сохранённые веса и открывает окно визуализации, где можно мышкой задавать точку назначения, включать автоприземление (L), регулировать и фиксировать скорость ветра, менять массу груза на лету и перезапускать эпизод.
